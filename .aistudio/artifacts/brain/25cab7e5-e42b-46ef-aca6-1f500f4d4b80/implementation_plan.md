# خطة تنفيذ لوحة تحكم الأدمن (التحقق المزدوج)

الهدف: بناء لوحة تحكم إشرافية (Admin) محمية عبر كلمة سر وبصمة صوتية (جملة صوتية).

## 1. آلية التحقق (Authentication)
- **المرحلة 1**: كلمة سر نصية.
- **المرحلة 2**: التحقق الصوتي باستخدام الجملة "طالب حوزة" عبر Web Speech API (لتحليل الجملة).

## 2. لوحة تحكم الأدمن (Admin Dashboard)
- واجهة إشراف عام للمنصة.
- التحكم في الجلسات، مراقبة المستخدمين، والإعدادات.

## 3. التنفيذ
- إنشاء مكون `AdminLogin.tsx` للتحقق المزدوج.
- إنشاء صفحة `AdminDashboard.tsx` لعرض أدوات الإشراف.
- إضافة الحماية عبر مسار محمي في التطبيق.
